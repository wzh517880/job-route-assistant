# 求职航线 · Chrome / Edge 扩展 v0.3.1

求职航线是一个本地求职工作台，支持岗位进度管理、简历资料库与网页辅助填写。本仓库已公开，当前程序文件为 v0.3.1 开发者模式预览版。

## 下载与安装

新用户请先阅读 **[下载与安装教程](USER_GUIDE.md)**，包含 Windows / Mac、Chrome / Edge 的安装步骤，以及“清单文件丢失”等常见问题的处理方法。

快捷步骤：**开启开发者模式 → 加载未打包 / 已解压的扩展程序 → 选择解压后的 job-route-assistant 文件夹**（从 GitHub 下载后也有可能名为 `job-route-assistant-main`）。旧版更新前先备份，详见 [INSTALL.md](INSTALL.md)。

## 当前功能

- 为不同目标岗位管理独立的简历版本，维护基本信息、教育、实习 / 工作、项目、校园、社会实践与荣誉成果，支持自定义模块标题和字段。
- 本地提取文字型 PDF 简历，生成可编辑草稿，需人工核对；扫描图片型 PDF 暂不支持自动识别。
- 网页侧栏选择简历版本和具体经历，单项填写或批量填写能明确识别的空白字段。单项填写会追加已有文本，下拉框会切换选项；批量填写排除身份证号及容易混淆的经历字段。扩展不点击网站提交、申请或确认按钮。
- 管理公司和岗位清单、投递状态、当前阶段截止时间、岗位详情、JD、HR 联系方式、面试链接、准备事项与备注。
- 记录状态时间线，保留历史截止时间，支持修正时间和备注；整理下一步事项并提示临近截止时间。
- 支持自定义状态及拖动、上下按钮、键盘排序。v0.3.1 默认增加“待测评”，新增岗位可直接在表格中编辑，详情入口与公司名称输入框分开。
- 本地留档投递使用的 PDF、Word 和图片原文件，单个文件最多 20 MB，可下载原文件，也可查看已有简历快照。
- 本地 OCR 识别通知截图，人工确认后转为投递记录。
- 导出及导入 JSON 备份；schema 4 包含岗位详情、时间线、简历留档和原文件，兼容 schema 1 / 2 / 3。导入会替换当前数据。

## 数据存放与当前风险

扩展的业务记录保存在当前浏览器的 `chrome.storage.local`，附件保存在 IndexedDB。直接作为普通页面运行时，记录使用该页面的 `localStorage`。PDF 和 OCR 使用随包文件处理输入，业务代码未发现主动上传简历或截图的请求。

**本地保存不代表当前版本已实现对网页的隐私隔离。** 网页侧栏在所有匹配的 HTTP / HTTPS 页面加载，使用开放的 Shadow DOM，并在加载时把简历值写入页面属性和文本。当前网页自己的脚本可能在用户尚未点击填写、侧栏仍收起时读取这些资料；页面还可能通过模拟侧栏事件切换版本和经历。因此，当前版本不适合真实资料试用。问题位置、修复方向和后续验证要求见 [SECURITY.md](SECURITY.md)。

仓库包含程序内明确标记的虚构示例，未附加个人简历、导出备份、演示 JSON 或浏览器数据目录。不要将使用过程中生成的备份、附件、截图或凭证提交到仓库；网页上传文件时也需人工核对，不能只依赖 `.gitignore`。

## 安装与核查

仅用于虚构资料测试。打开 `chrome://extensions/` 或 `edge://extensions/`，开启开发者模式，选择“加载已解压的扩展程序”，加载本目录中直接包含 `manifest.json` 的这一层。

安装和旧版更新步骤保留在 [INSTALL.md](INSTALL.md)。该文件是原版说明，按其操作前请先遵守上面的测试限制。更新前先导出备份，不要先卸载旧版；备份应保存在仓库之外。

点击工具栏扩展图标可打开看板。网页侧栏可通过悬浮按钮或 `Alt + J`（Windows）/ `Option + J`（Mac）切换。独立演示入口为 `dashboard.html?preview=phase1#records`，使用单独的示例记录和附件存储。

已知兼容性问题：先前 Windows Edge 上悬浮球不显示的原因尚未定位，v0.3.1 不代表该问题已修复。当前也未接入浏览器商店自动更新。
